# WoT Blitz (.sc2) importer for Blender

Импортирует танки World of Tanks Blitz 0.4.7 прямо из клиентских файлов:
части корпуса/башни/орудия/гусениц/катков по отдельности, любой LOD,
броню (отдельными пластинами с реальной толщиной в мм) и текстуры.

## Как это устроено

Модели `.sc2` — это бинарный формат движка DAVA (`SceneFileV2`), в котором
хранится дерево сцены + геометрия (позиции/нормали/UV) прямо внутри файла.
Броня хранится **отдельно**, в `Data/3d/Tanks/CollisionMeshes/<нация>-<Имя>.sc2`
— это упрощённая коллизионная геометрия, где толщина брони в мм буквально
записана как float в каждой вершине (это подтверждено экспериментально:
все 3 вершины любого треугольника всегда дают одинаковое значение,
и набор значений совпадает с `<armor>` в XML танка).

Аддон не использует и не требует стороннего конвертера — весь парсер
написан с нуля на чистом Python (`wotb_importer/ka_format.py`,
`polygon_group.py`, `scene_tree.py`, `armor.py`, `materials.py`, `textures.py`).

## Установка

1. Заархивируйте папку `wotb_importer` в `wotb_importer.zip`
   (или используйте уже готовый архив рядом с этим README).
2. В Blender: `Edit > Preferences > Add-ons > Install...`, выберите zip.
3. Включите галочку у аддона "WoT Blitz (.sc2) importer".
4. В 3D-вьюпорте откройте боковую панель (клавиша `N`) — появится вкладка **WoTB**.

## Использование

1. **Tanks folder** — укажите `...\WoTB\Data\3d\Tanks`.
2. Выберите **Nation** и **Tank**.
3. Нажмите **Scan tank** — аддон разберёт файл и покажет:
   - сколько LOD-уровней доступно (LOD0 — самый детальный);
   - список модулей (Hull, Turret_01/02, Gun_02/03/05, Chassis_L/R,
     Track_L/R, Track_Crash_L/R, Wheels_L/R, Locators) с чекбоксами.
4. Отметьте нужные LOD и модули.
5. **Import textures** — подтянуть текстуры, если пиксельные данные реально
   есть на диске (см. ограничение ниже). **Skin** — если у танка есть
   альтернативный камуфляж/скин, можно выбрать вариант.
6. **Import armor** — добавить коллекцию `Armor` с отдельными объектами
   по каждой броневой пластине: `armor_hull_<мм>`, `armor_turret_01_<мм>`
   / `armor_turret_02_<мм>`, а для маски орудия — `gun_mask_<мм>`
   (толщина всегда числом после последнего `_`, без "mm"). У каждого
   объекта есть custom-property `armor_thickness_mm` (видно в N-panel >
   Item) и материал, раскрашенный по толщине (синий=тонкая, красный=толстая).
7. Нажмите **Import**.

## Имена объектов визуальной модели

- Корпус: `hull_vis_LODn`; колёса (`wheelL1`…`wheelL11`, `wheelR1`…`wheelR11`)
  импортируются как дочерние объекты корпуса того же LOD.
- Башни: `turret01_LODn`, `turret02_LODn`. Орудия: `gun02_LODn`, `gun03_LODn`,
  `gun05_LODn`. Гусеницы: `trackL_LODn`, `trackR_LODn`.
- Разбитые гусеницы (`chassis_track_crash_L/R`) объединяются в один объект
  `tracks_crash_LODn` (один меш, два материал-слота — левая/правая).

## Ориджины (origin)

Ориджин каждого объекта берётся не из bounding box, а из реальных игровых
данных:
- Корпус, катки, гусеницы, шасси, брекейдж-локаторы — ориджин в (0,0,0):
  сама игра хранит их с единичной трансформацией относительно корпуса,
  отдельного пивота для них в файлах нет.
- Башни (`turret01`/`turret02`) — ориджин в точке погона башни
  (`hull/turretPositions/turret` из XML танка) — это и есть реальная ось
  поворота башни в игре.
- Орудия (`gun02`/`gun03`/`gun05`) и маски орудия в броне (`gun_mask_*`) —
  ориджин в точке качания ствола (погон башни + `gunPosition` из XML) —
  реальная ось вертикальной наводки.
- Броня корпуса (`armor_hull_*`) — ориджин в (0,0,0), как и сам корпус.
  Броня башни/маски орудия — в тех же точках погона/качания, что и
  соответствующие визуальные части, так что поворот брони синхронен
  с поворотом видимой геометрии.

Мировое положение геометрии при этом не меняется — меняется только то,
где у объекта "штырёк" (origin), вокруг которого он поворачивается/
масштабируется.

## Известные ограничения

- **Текстуры есть не для всех танков.** В `.tex`-файлах хранится только
  22-байтный дескриптор, реальные пиксели (`.pvr`/`.dds`) докачиваются
  отдельно и во многих установках просто отсутствуют на диске для
  неиспользуемых/неисследованных танков. Если файла нет — аддон тихо
  пропускает текстуру, оставляя материал без неё (но с правильным именем).
- **Формат PVR** декодируется только для несжатых пиксельных форматов.
  Блочно-сжатые (PVRTC/ETC) не декодируются — при необходимости
  конвертируйте такие текстуры заранее через бесплатный `PVRTexToolCLI`.
- **DDS** загружается через встроенный загрузчик изображений Blender —
  для большинства DXT/BC текстур работает "из коробки".
- Позиционирование брони башни/орудия относительно корпуса берётся из
  `Data/XML/item_defs/vehicles/<нация>/<Имя>.xml` (`turretPositions`,
  `gunPosition`) — если структура XML для какого-то танка нестандартна,
  возможен небольшой остаточный сдвиг.
- Углы поворота башни/орудия (наводка) не применяются — импортируется
  "нулевая" статичная поза, как и сама визуальная модель.

## Проверено на

- WoT Blitz 0.4.7, IS-3 (без текстур в дистрибутиве — геометрия/броня
  проверены), STA_1 (с реальной DDS-текстурой — текстурный пайплайн
  проверен целиком).
